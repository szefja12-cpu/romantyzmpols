ROMANTYZM — GOTOWA PACZKA DO GITHUB PAGES

1. Wejdź na https://github.com/ i zaloguj się.
2. Kliknij „New repository”.
3. Nazwij repozytorium np. romantyzm.
4. Wybierz „Public” i utwórz repozytorium.
5. W repozytorium kliknij „Add file” → „Upload files”.
6. Wgraj WSZYSTKIE pliki z tej paczki:
   - index.html
   - styles.css
   - script.js
   - .nojekyll
7. Kliknij „Commit changes”.
8. Wejdź w „Settings” → „Pages”.
9. W sekcji „Build and deployment” wybierz:
   Source: Deploy from a branch
   Branch: main / root
10. Zapisz ustawienia.
11. Po chwili GitHub poda adres strony. Będzie on wyglądał mniej więcej tak:
   https://TWOJ_LOGIN.github.io/romantyzm/

WAŻNE:
- Plik index.html musi znajdować się w głównym katalogu repozytorium.
- Nie zmieniaj nazw index.html, styles.css i script.js, chyba że poprawisz również odwołania w HTML.
- Strona korzysta z części materiałów graficznych ładowanych z internetu, więc przeglądarka powinna mieć połączenie z siecią.
